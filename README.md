## Sun Devil Rocketry Document Control

This repository holds version controlled documentation for Sun Devil Rocketry's projects. This includes:
- Hazard Analyses
- Requirements Documents
- Quality Assurance Standards & Compliance Documents

### Rules

This repository has stricter rules than the rest of the organization. **WITHOUT EXCEPTION**, we require:
- Commits to be signed by the author (to authenticate the user who added/modified documentation)
- Pull requests with at least one approval prior to merging (to enforce reviews of controlled documents)
- No merge commits allowed (to preserve linear commit history)
- No force pushes allowed (to prevent rewriting history)

### Recommendations

The "living/working" versions of documents should live in a separate location, such as the SDR google drive. Links
should reference the controlled version of other documents rather than the living version, if applicable.
